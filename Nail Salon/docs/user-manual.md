# Manual de usuario

## Cliente
1. Regístrate y crea tu cuenta.
2. Inicia sesión y navega por servicios.
3. Reserva una cita seleccionando fecha y horario.
4. Revisa tus citas y cancela si es necesario.

## Administrador
1. Inicia sesión con rol admin.
2. Accede al dashboard para ver métricas.
3. Gestiona servicios, clientes y citas desde el panel.
4. Cambia estados de cita según el avance del servicio.
